# Due diligence skills

Claude skills for acquisition due diligence on data-center deals. Each folder under `skills/` is one skill (`SKILL.md` plus any `references/` and `scripts/`).

| Skill | What it does |
|---|---|
| dd-checklist | Reconcile a DD checklist against a data room / seller tracker |
| dd-customer-invoice-extract | Customer invoices → reconciled kW / MRC workbook |
| jax-tenant-agreement-extraction | Tenant agreements → Customer Agreements Summary workbook |
| lease-review | Answer lease questions with cites and page snips |
| review-lease-claims | Verify each lease-review claim against its snip (runs after lease-review) |
